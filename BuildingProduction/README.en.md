# Building Production

See what each production building actually consumes and delivers.

- Resource icons show consumption in red and output in green.
- Large number: monthly average over up to 12 completed game months. Small number: this month so far. A dash means not enough history.
- Workshop product buttons remain usable. Quarry stone piles and unused dairy herds have stock bars.
- An amber quarry bar and ox warning mean the pile is at least 90% full; check transport. This does not calculate an exact ox-tether shortage.

Enabled by default. Tracks local-player buildings. Statistics restart on new game/load; the month a building is constructed is excluded from its completed-month average. Debug.LogEvents is off by default.

Client-side display only. Multiplayer untested.

Requires Script Extender 2.10.1+ and BepInEx Loader (install loader first). Subscribe and restart when prompted. Manual install: merge the ZIP’s BepInEx folder into the game folder; move an old short-name plugin folder outside plugins first, preserving config.

[Script Extender](https://gitlab.com/rawra-stronghold-crusader/shcde-script-extender/-/releases)

Mod Options → Building Production · `BepInEx/config/BuildingProduction_Dongge.cfg`
