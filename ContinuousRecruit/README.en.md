# Continuous Recruit

Keep recruiting selected troop types without repeated clicks.

- Right-click a troop portrait or press Shift+Alt+1…8 to toggle that slot. Active portraits show ∞.
- Supports Barracks, Mercenary Post, Bedouin Stockade, Engineers Guild, Tunnelers Guild and Cathedral.
- By default, attempts one recruit per enabled troop type every second using the game’s normal recruitment command. Normal costs and requirements still apply.
- Recruitment waits during pause or when requirements are unmet. New games, loads and disabling the feature clear all active troop types.

Feature enabled by default; no troop type is active until you choose one. General.RecruitIntervalSeconds accepts 0.25–10 seconds (default 1).

Uses normal recruitment commands. Multiplayer untested.

Requires Script Extender 2.10.1+ and BepInEx Loader (install loader first). Subscribe and restart when prompted. Manual install: merge the ZIP’s BepInEx folder into the game folder; move an old short-name plugin folder outside plugins first, preserving config.

[Script Extender](https://gitlab.com/rawra-stronghold-crusader/shcde-script-extender/-/releases)

Mod Options → Continuous Recruit · `BepInEx/config/ContinuousRecruit_Dongge.cfg`

Chinese and English fallback; restart after changing language. Feedback: include mod, game and extender versions and reproduction steps.
