# 连续招募

持续招募选定兵种，减少重复点击。

- 右键兵种头像，或按 Shift+Alt+1…8 切换对应位置的兵种；开启后显示 ∞。
- 支持兵营、雇佣兵营地、贝都因营地、工程师行会、坑道兵行会和大教堂。
- 默认每秒为每个已开启兵种尝试招募一个，使用游戏原版招募命令，照常消耗资源并检查条件。
- 暂停或不满足条件时等待；新局、读档或关闭功能会清除全部已开启兵种。

功能默认开启，但须手动选择兵种才会招募。General.RecruitIntervalSeconds 可设 0.25–10 秒，默认 1 秒。

使用原版招募命令，联机未测试。

需要 Script Extender 2.10.1+ 和 BepInEx Loader，先安装 Loader、再安装扩展器。工坊订阅后按提示重启。手动安装：将 ZIP 中 BepInEx 合并到游戏目录；旧版短名称插件目录须先移出 plugins，保留配置。

[Script Extender](https://gitlab.com/rawra-stronghold-crusader/shcde-script-extender/-/releases)

Mod Options → Continuous Recruit · `BepInEx/config/ContinuousRecruit_Dongge.cfg`
