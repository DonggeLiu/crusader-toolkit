# 建筑对齐网格

用局部网格对齐建筑、预留通道。

- 放置建筑时，在鼠标周围显示由近及远渐淡的网格。
- 配置中可调整半径（3–15 格）、颜色和屏幕像素线宽。
- 只提供对齐参考，不改变建造规则。

默认开启。General.Radius 默认 8 格；Appearance.Color 和 LineWidthPixels 控制颜色与线宽。

纯客户端显示，联机未测试。

需要 Script Extender 2.10.1+ 和 BepInEx Loader，先安装 Loader、再安装扩展器。工坊订阅后按提示重启。手动安装：将 ZIP 中 BepInEx 合并到游戏目录；旧版短名称插件目录须先移出 plugins，保留配置。

[Script Extender](https://gitlab.com/rawra-stronghold-crusader/shcde-script-extender/-/releases)

Mod Options → Build Grid · `BepInEx/config/BuildGrid_Dongge.cfg`
