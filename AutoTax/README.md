# Auto Tax / 自动调税 1.0.0

单人自动税率管理，默认开启。当前为开发版本，尚未实机验收或上传。需要 BepInEx 和 Script Extender 2.10.1+。

## 当前策略

- 暂定可调目标区间 **99–99.5**，设置按钮每次调整 0.25；下限必须小于上限，上限须低于 100。无效组合停止调整并提示。
- 按食物等实际民心贡献动态计算税档。到下限时，选择仍能增加民心的最高税档；到上限时，选择开始消耗民心的最低税档。有合适的收支持平税档则保持。
- 达到 100 时立即重新评估加税，并尽量提前避免已知的封顶浪费。不再按整月等待，也不限定每次只调一档。运行时每 0.25 现实秒检查一次，暂停时不调整。
- **自动策略永远不选择补贴。** 手动选择补贴时保留该选择，手动切回零税或征税后恢复接管。没有“允许自动补贴”选项。
- 恢复不写死为零税：额外加成足够时，可以一边收税一边恢复。若零税仍无法恢复，提示需要处理其他原因，不自动花钱。
- 税档效果是离散的，目标区间不是硬边界；加成变化、缺粮等情况仍可能使民心越界。
- 仅管理本地单人玩家；联机、观战、编辑器及人口不超过 3 的特殊经济阶段不调整。关闭后保留当前税率。

在税收羊皮纸内开关本局自动调税、调整上下限并查看状态。每次调整 0.25，按钮自动限制边界，避免上下限交叉。暂停时可以改设置，恢复游戏后执行调税。

Mod Options → Auto Tax 仅设置新局默认值。本局设置嵌入正常游戏存档，读档恢复；旧存档没有该数据时采用默认值。本局调整不会改写新局默认值，仍需正常保存游戏才能保留本次修改。

税档 0–2 为补贴、3 为零税、4–11 为征税。配置文件：`BepInEx/config/AutoTax_Dongge.cfg`。

## 税收羊皮纸与额外收益

控件嵌入要塞税收羊皮纸：火漆印切换本局开关，状态行显示决定、民心和调整次数，悬停可查看原因；小三角以 0.25 步长调整目标。滑槽会随自动调税移动，并显示短暂金光与轨迹。

“额外收益”对比接管时原税率保持不变的参考收入，不是累计税收总额，也不是另一局实测的因果增收。开关、目标、额外收益、基线及调整次数随正常存档保存。旧格式存档保留可读取的设置，额外收益从零开始。
