# Granary Overview

Compare rations and food supply in one granary panel.

- Combines food switches, stock, monthly changes and ration controls on one page, using the game’s icons.
- Shows estimated monthly balance and how long stock may last under each ration level.
- Suggests additional farms or bread-chain buildings when estimated production falls short.
- Production uses recent deliveries (up to three game months); market purchases do not count as production. Estimates need about a quarter month to warm up after loading.

Enabled by default. Building counts and time remaining are estimates, affected by delivery distance and recent production. Without samples, building rates use fallback estimates. Debug.LogFood is off by default.

Client-side display only. Multiplayer untested.

Requires Script Extender 2.10.1+ and BepInEx Loader (install loader first). Subscribe and restart when prompted. Manual install: merge the ZIP’s BepInEx folder into the game folder; move an old short-name plugin folder outside plugins first, preserving config.

[Script Extender](https://gitlab.com/rawra-stronghold-crusader/shcde-script-extender/-/releases)

Mod Options → Granary Overview · `BepInEx/config/GranaryOverview_Dongge.cfg`
