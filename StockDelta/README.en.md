# Stock Delta

See whether your stocks are growing or shrinking.

- Adds signed net changes below stockpile, granary food-report and armoury counts.
- Large number: previous game month. Small number after the dot: this month so far. Green means gain; red means loss.
- Includes all stock changes, including trade and consumption; it is not a production-only statistic.
- Statistics restart on a new game or load. A dash means no previous interval is available; the first interval after loading may be a partial month.

Enabled by default. Works independently. With Granary Overview, that mod supplies its own granary totals; Stock Delta still covers the other storage/report panels.

Client-side display only. Multiplayer untested.

Requires Script Extender 2.10.1+ and BepInEx Loader (install loader first). Subscribe and restart when prompted. Manual install: merge the ZIP’s BepInEx folder into the game folder; move an old short-name plugin folder outside plugins first, preserving config.

[Script Extender](https://gitlab.com/rawra-stronghold-crusader/shcde-script-extender/-/releases)

Mod Options → Stock Delta · `BepInEx/config/StockDelta_Dongge.cfg`
