# 库存净变化

直接看出库存是在增加还是减少。

- 在库房、粮仓食物报告和武器库的数量下方显示库存净变化。
- 大字为上个游戏月，小字为本月至今；绿色增加、红色减少。
- 包含交易、消耗等全部库存变化，不等于纯生产量。
- 新局或读档后重新统计；没有上个区间时显示横线，读档后的首个统计区间可能不足整月。

默认开启，可独立使用。与粮仓总览同时安装时，粮仓由总览提供统计，其他仓储/报告页面仍由本 mod 显示。

纯客户端显示，联机未测试。

需要 Script Extender 2.10.1+ 和 BepInEx Loader，先安装 Loader、再安装扩展器。工坊订阅后按提示重启。手动安装：将 ZIP 中 BepInEx 合并到游戏目录；旧版短名称插件目录须先移出 plugins，保留配置。

[Script Extender](https://gitlab.com/rawra-stronghold-crusader/shcde-script-extender/-/releases)

Mod Options → Stock Delta · `BepInEx/config/StockDelta_Dongge.cfg`
