# 神骑妙躲

Artful Dodger

弓骑兵自动躲开箭矢、弩箭和石头，零伤亡拔掉敌方箭塔。

- 选中弓骑兵，按小键盘 `.` 开启/关闭它们的躲避。
- 开启后照常原地射击，只在敌方飞行物快要落到身上时才移动，躲完回到你命令的位置。
- 识别箭、弩箭（包括塔上射来的）、各种石头、巨弩箭、投石兵石头、火罐和标枪；已实测弓手、弩手、射石机和巨弩。
- 躲避位置尽量保持敌人在射程内、与射手保持安全距离、避免互相挤撞。
- 可选风筝：近战敌人靠近时边退边保持在射程内。
- 实测（10 名弓骑兵）：野战命中率约 95% → 2% 以下；进攻 10 弓手 + 5 弩手的塔（另两座驻军塔掩护），站着不动全灭且零击杀，开启躲避零伤亡清空。

Mod Options → Artful Dodger：总开关、躲避近战、新招募的弓骑兵默认开启。快捷键见配置 `[General] ToggleKey`。仅限弓骑兵；地上的火、火盆和沸油不躲。

为单人游戏设计。联机未经测试，可能导致不同步，风险自负。

需要 Script Extender 2.10.1+ 和 BepInEx Loader，先安装 Loader、再安装扩展器。工坊订阅后按提示重启。手动安装：将 ZIP 中 BepInEx 合并到游戏目录。
