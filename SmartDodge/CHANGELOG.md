# Changelog

## 1.0.1

- Renamed from Smart Dodge to Artful Dodger (Chinese: 神骑妙躲). GUID, install folder and config file are unchanged, so settings carry over.
- Dodging behavior is unchanged.

## 1.0.0

First release.

- Select horse archers and press Numpad . to toggle dodging for them (Mod Options: master switch, kite melee, auto-enable for new horse archers).
- Dodging horse archers stand and shoot; they step aside only when an arrow, crossbow bolt, stone, ballista bolt, sling stone or fire pot is about to land within reach, including shots from towers.
- After a dodge they return to your last move order. They prefer spots that keep the enemy in range and avoid running into each other.
- Optional kiting: back away from approaching melee enemies while staying in range.
- Developer test tools are off by default (`[Test] TestTools`).
